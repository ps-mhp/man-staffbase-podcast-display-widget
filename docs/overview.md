# Podcast-Anzeige

Die Podcast-Anzeige bettet einen einzelnen Podcast-Player in eine Seite ein.
Sie kann entweder immer die **neueste Episode** eines Podcasts zeigen — das
Widget aktualisiert sich dann von selbst, sobald eine neue Folge erscheint —
oder dauerhaft eine **bestimmte, fest ausgewählte Episode**.

Das Widget eignet sich für Podcast-Landingpages, Team- oder Kanalseiten sowie
für einzelne Beiträge, die auf eine bestimmte Folge verweisen sollen.
