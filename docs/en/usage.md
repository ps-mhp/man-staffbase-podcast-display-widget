# Step by Step

## Always Show the Latest Episode

1. Open the target page for editing and drag the **Podcast Display** widget to the
   desired location.
2. Under **Podcast ID**, select the podcast from the drop-down list.
3. Leave **Display Mode** set to `Latest Episode` (default).
4. Select **Player Size**: `Large` for wide areas, `Compact` for narrow
   columns.
5. Save and check the preview.

From now on, the display will update automatically whenever a new episode is released.

## Display a Specific Episode

1. Open the target page for editing and drag the **Podcast Display** widget to the
   desired location.
2. Under **Podcast ID**, select the podcast from the drop-down list.
3. Change **Display Mode** to `Specific Episode`. Only then will the
   **Episode ID** field be used.
4. Under **Episode ID**, select the desired episode from the drop-down list.
5. Select **Player Size**.
6. Save and check the preview.

## If no drop-down list appears

Instead of the list, you’ll see a message stating that podcasts or episodes could not
be loaded. In that case, enter the information manually:

1. For the **Podcast ID**: Open the podcast in Staffbase and paste the
   full URL from the address bar into the field.
2. For the **Episode ID**: Paste the episode identifier or the full URL
   of the audio file into the field.
3. Save. In both cases, the widget will automatically retrieve
   the actual ID.

## If a podcast is missing from the list

1. Click the link **“Can’t find the podcast?”** below the selection—it
   lists the common causes.
2. Check whether the podcast’s Space is accessible from this page;
   only accessible podcasts are listed.
3. If necessary, enter the podcast ID manually—but then verify whether the
   page’s target audience is even allowed to listen to the episode.
