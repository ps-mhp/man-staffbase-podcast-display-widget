# Settings

| Setting | Description |
| --- | --- |
| Podcast | The podcast from which an episode is displayed. Required field. |
| Display Mode | “Latest Episode” always shows the most recent episode; “Specific Episode” permanently displays the episode selected below. |
| Episode | Visible only in “Specific Episode” display mode: the specific episode to be displayed. |
| Player Size | “Large” displays the cover, title, and full controls; “Small” displays a compact row with Play/Pause. |

The podcast and episode can be easily selected using the drop-down menu in the
configuration dialog; if, in rare cases, a list is not available,
the respective ID can also be entered manually.
