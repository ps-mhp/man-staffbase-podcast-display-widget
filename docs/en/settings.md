# Settings

| Setting | Description |
| --- | --- |
| Podcast ID | The podcast from which an episode is displayed. Required field. Usually selected from the drop-down list; alternatively, enter the full podcast URL. |
| Display Mode | `Latest Episode` (default) always displays the most recent episode. `Specific Episode` permanently displays the episode selected below. |
| Episode ID | Only effective in `Specific Episode` mode. The desired episode — via the drop-down list or as an identifier or the full URL of the audio file. |
| Player Size | `Large` (default): Cover art, title, date, full controls including playback speed and mute. `Compact`: narrow tile with play and progress indicators. |

## Notes

- In `Latest Episode` mode, any value entered under “Episode ID”
  is simply ignored—it does not need to be deleted.
- The episode selection list will not populate until a podcast
  is selected at the top.
- Changing the player size only alters the display, not the
  episode currently playing.
