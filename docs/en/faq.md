# FAQ

**Question:** The configuration dialog says, “The list of podcasts could not
be loaded. Please enter the installation ID.”

Answer: The drop-down list is just a convenience feature. Open the podcast in
Staffbase and paste the full address into the **Podcast ID**
field. It often helps to close the dialog and then
reopen it.

**Question:** The configuration dialog says, “The list of episodes could not be
loaded (or no podcast has been selected yet).”

Answer: First, select a podcast at the top—without a podcast, there is no
episode list. If the list remains empty, enter the episode ID or the
full address of the audio file manually.

**Question:** A specific podcast is missing from the drop-down list.

Answer: Only podcasts accessible from this page are listed.
The link **“Can’t find the podcast?”** below the selection explains the
common causes—usually a lack of access rights to the podcast’s
space. You can still enter the ID manually; however, you should then
verify whether the page’s target audience is actually allowed to listen to the episode.

**Question:** The page says “No podcast ID configured.”

Answer: The **Podcast ID** field is empty. Select a podcast or enter the
address and save.

**Question:** The page says “‘Specific Episode’ mode selected, but
no episode ID configured.”

Answer: The display mode is set to `Specific Episode`, but no
episode selected. Either select an episode or switch back to `Latest Episode`
.

**Question:** The page says “The podcast does not have any episodes yet.”

Answer: The podcast exists but does not contain any playable episodes. First,
publish an episode in Staffbase.

**Question:** The page says “Episode not found.”

Answer: The episode you entered does not (or no longer) exist in this podcast—for example,
after it was deleted or if the episode and podcast don’t match. Select a new episode
or switch to `Latest Episode`.

**Question:** The episode displayed changes on its own.

Answer: This is exactly how it’s supposed to work in `Latest Episode` mode. If you want
the same episode to be displayed permanently, switch to `Specific Episode`.

**Question:** Why are the speed and
mute controls missing from the compact player?

Answer: The compact player is intentionally limited to Play/Pause and progress
so that it fits into narrow columns. If you need full control,
select the `Large` player size.

**Question:** Can I display multiple episodes as a list?

Answer: No, a widget plays exactly one episode. To display multiple episodes, place multiple
widgets.
