# FAQ

**Question:** The widget displays “The list of podcasts could not be loaded
” in the configuration dialog—what should I do?

Answer: In this case, you can enter the podcast ID manually. This is usually
due to a temporary glitch in the podcast interface;
reopening the dialog usually resolves the issue.

**Question:** Why does the displayed episode change on its own?

Answer: In “Latest Episode” display mode, this is by design—the widget
always shows the most recent episode of the selected podcast, without any further
action required. If you want a specific episode to be displayed permanently, switch to “Specific
Episode” and select the desired episode.
