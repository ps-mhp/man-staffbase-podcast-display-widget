# Anuncio de podcast

El anuncio de podcast integra un reproductor de podcast único en una página.
Puede mostrar siempre el **último episodio** de un podcast —el
en cuyo caso el widget se actualiza automáticamente en cuanto aparece un nuevo episodio—
o mostrar de forma permanente un **episodio concreto y seleccionado**.

El widget es ideal para páginas de destino de podcasts, páginas de equipo o de canal, así como
para entradas individuales que deban remitir a un episodio concreto.
