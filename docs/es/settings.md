# Ajustes

| Ajuste | Descripción |
| --- | --- |
| Podcast | El podcast del que se muestra un episodio. Campo obligatorio. |
| Modo de visualización | «Último episodio» muestra siempre el episodio más reciente; «Episodio específico» muestra de forma permanente el episodio seleccionado a continuación. |
| Episodio | Solo visible en el modo de visualización «Episodio específico»: el episodio concreto que se va a mostrar. |
| Tamaño del reproductor | «Grande» muestra la portada, el título y todos los controles; «Pequeño» muestra una línea compacta con los botones de reproducción/pausa. |

El podcast y el episodio se pueden seleccionar fácilmente mediante el menú desplegable del
cuadro de diálogo de configuración; si, excepcionalmente, no hay una lista
disponible, también se puede introducir manualmente el ID correspondiente.
