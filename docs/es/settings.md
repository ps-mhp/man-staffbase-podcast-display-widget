# Configuración

| Configuración | Descripción |
| --- | --- |
| ID del podcast | El podcast del que se muestra un episodio. Campo obligatorio. Normalmente se selecciona de la lista desplegable; en su defecto, introduce la dirección completa del podcast. |
| Modo de visualización | «Episodio más reciente» (ajuste predeterminado) muestra siempre el episodio más reciente. «Episodio específico» muestra de forma permanente el episodio seleccionado a continuación. |
| ID del episodio | Solo es válido en el modo «Episodio específico». El episodio deseado: a través de la lista de selección o como identificador o dirección completa del archivo de audio. |
| Tamaño del reproductor | `Grande` (predeterminado): portada, título, fecha y controles completos, incluyendo velocidad y silencio. `Compacto`: mosaico estrecho con botones de reproducción y progreso. |

## Notas

- En el modo `Último episodio`, cualquier valor introducido en «ID del episodio»
  se ignora simplemente; no es necesario borrarlo.
- La lista de selección de episodios solo se rellena cuando se selecciona un podcast
  en la parte superior.
- Cambiar el tamaño del reproductor solo modifica la presentación, no el
  episodio que se está reproduciendo.
