# Preguntas frecuentes

**Pregunta:** El widget muestra el mensaje «No se ha podido cargar la lista de podcasts»
en el cuadro de diálogo de configuración. ¿Qué puedo hacer?

Respuesta: En este caso, el ID del podcast se puede introducir manualmente. Normalmente
se debe a un fallo temporal de la interfaz del podcast; por lo general,
volver a abrir el cuadro de diálogo soluciona el problema.

**Pregunta:** ¿Por qué cambia por sí solo el episodio que se muestra?

Respuesta: En el modo de visualización «Último episodio», esto es intencionado: el widget muestra
siempre el episodio más reciente del podcast seleccionado, sin necesidad de
ninguna acción adicional. Si se desea que se muestre un episodio concreto de forma permanente, cambia a «Episodio
concreto» y selecciona el episodio deseado.
