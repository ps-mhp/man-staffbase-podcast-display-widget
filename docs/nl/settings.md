# Instellingen

| Instelling | Beschrijving |
| --- | --- |
| Podcast-ID | De podcast waarvan een aflevering wordt weergegeven. Verplicht veld. Meestal via de keuzelijst; voer anders het volledige podcastadres in. |
| Weergavemodus | `Nieuwste aflevering` (standaard) toont altijd de meest recente aflevering. `Specifieke aflevering` toont permanent de hieronder geselecteerde aflevering. |
| Afleverings-ID | Alleen van toepassing in de modus `Specifieke aflevering`. De gewenste aflevering — via de keuzelijst of als ID of volledig adres van het audiobestand. |
| Spelerformaat | `Groot` (standaard): omslag, titel, datum, volledige bediening inclusief afspeelsnelheid en dempen. `Compact`: smalle tegel met afspeelknop en voortgangsbalk. |

## Opmerkingen

- In de modus `Nieuwste aflevering` wordt een ingevoerde waarde onder „Aflevering-ID“
  gewoon genegeerd — deze hoeft niet te worden gewist.
- De keuzelijst met afleveringen wordt pas gevuld als er bovenaan een podcast
  is geselecteerd.
- Het wijzigen van de afspeelgrootte verandert alleen de weergave, niet de
  afgespeelde aflevering.
