# Instellingen

| Instelling | Beschrijving |
| --- | --- |
| Podcast | De podcast waarvan een aflevering wordt weergegeven. Verplicht veld. |
| Weergavemodus | „Nieuwste aflevering“ toont altijd de meest recente aflevering; 'Specifieke aflevering' toont permanent de hieronder geselecteerde aflevering. |
| Aflevering | Alleen zichtbaar bij weergavemodus 'Specifieke aflevering': de specifieke aflevering die moet worden weergegeven. |
| Spelergrootte | 'Groot' toont de hoes, titel en volledige bediening; „Klein“ toont een compacte regel met afspelen/pauzeren. |

Podcast en aflevering kunnen gemakkelijk worden geselecteerd via het dropdown-menu in het
configuratievenster; mocht er bij uitzondering geen lijst beschikbaar zijn,
dan kan de betreffende ID ook handmatig worden ingevoerd.
