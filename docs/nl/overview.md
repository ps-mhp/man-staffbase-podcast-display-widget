# Podcast-widget

De podcast-widget integreert een enkele podcastspeler in een pagina.
Deze kan ofwel altijd de **nieuwste aflevering** van een podcast weergeven — de
de widget wordt dan automatisch bijgewerkt zodra er een nieuwe aflevering verschijnt —
of permanent een **bepaalde, vast gekozen aflevering**.

De widget is geschikt voor podcast-landingspagina’s, team- of kanaalpagina’s en
voor afzonderlijke berichten die naar een bepaalde aflevering moeten verwijzen.
