# Étape par étape

## Afficher systématiquement le dernier épisode

1. Ouvrez la page de destination à modifier et faites glisser le widget **Affichage du podcast** à l'
  emplacement souhaité.
2. Sous **ID du podcast**, sélectionnez le podcast dans la liste déroulante.
3. Laissez **Mode d'affichage** sur `Dernier épisode` (réglage par défaut).
4. Choisissez la **Taille du lecteur** : `Grand` pour les zones larges, `Compact` pour les
   colonnes étroites.
5. Enregistrez et vérifiez dans l'aperçu.

Désormais, l'affichage se mettra à jour automatiquement à chaque nouvel épisode.

## Afficher un épisode spécifique

1. Ouvrez la page de destination à modifier et faites glisser le widget **Affichage du podcast** à l’
  emplacement souhaité.
2. Sous **ID du podcast**, sélectionnez le podcast dans la liste déroulante.
3. Réglez le **Mode d’affichage** sur « Épisode spécifique ». Ce n’est qu’ainsi que le
   champ **ID de l’épisode** sera utilisé.
4. Sous **ID de l’épisode**, sélectionnez l’épisode souhaité dans la liste déroulante.
5. Choisissez la **Taille du lecteur**.
6. Enregistrez et vérifiez dans l’aperçu.

## Si aucune liste de sélection n’apparaît

À la place de la liste, un message indique alors que les podcasts ou les épisodes n’ont pas
pu être chargés. Dans ce cas, saisissez les informations manuellement :

1. Pour l’**ID du podcast** : ouvrez le podcast dans Staffbase et
   copiez l’adresse complète depuis la barre d’adresse pour la coller dans le champ.
2. Pour l’**ID de l’épisode** : copiez l’identifiant de l’épisode ou l’adresse complète
   du fichier audio pour la coller dans le champ.
3. Enregistrez. Dans les deux cas, le widget récupère lui-même l’ID
   correspondant.

## Si un podcast manque dans la liste

1. Cliquez sur le lien **« Podcast introuvable ? »** sous la sélection — vous y
   trouverez les causes habituelles.
2. Vérifiez si l’espace dédié au podcast est accessible depuis cette page ;
   seuls les podcasts accessibles sont répertoriés.
3. Si nécessaire, saisissez manuellement l’ID du podcast — mais vérifiez alors si le
   public cible de la page est autorisé à écouter cet épisode.
