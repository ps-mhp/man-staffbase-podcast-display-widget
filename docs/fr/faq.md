# FAQ

**Question :** Dans la boîte de dialogue de configuration, le message suivant s'affiche : « Impossible de charger la liste des podcasts.
Veuillez saisir l'ID d'installation. »

Réponse : La liste de sélection n'est qu'une aide pratique. Ouvrez le podcast dans
Staffbase et collez l'adresse complète dans le champ **ID du podcast**.
Il est souvent utile de fermer la boîte de dialogue puis de la
rouvrir.

**Question :** Dans la boîte de dialogue de configuration, le message suivant s'affiche : « La liste des épisodes n'a pas pu
être chargée (ou aucun podcast n'a encore été sélectionné). »

Réponse : Commencez par sélectionner un podcast en haut — sans podcast, il n’y a pas de
liste d’épisodes. Si la liste reste vide, saisissez manuellement l’identifiant de l’épisode ou l’
adresse complète du fichier audio.

**Question :** Un podcast spécifique manque dans la liste de sélection.

Réponse : Seuls les podcasts accessibles depuis cette page
sont répertoriés. Le lien **« Podcast introuvable ? »** situé sous la liste explique les
causes habituelles — généralement un manque de droits d’accès à l’espace du
podcast. L’ID peut néanmoins être saisi manuellement ; il convient toutefois de
vérifier si le public cible de la page est autorisé à écouter cet épisode.

**Question :** La page affiche « Aucun ID de podcast configuré. »

Réponse : Le champ **ID de podcast** est vide. Sélectionnez un podcast ou saisissez son
adresse, puis enregistrez.

**Question :** La page affiche « Mode « Épisode spécifique » sélectionné, mais
aucun ID d’épisode configuré. »

Réponse : Le mode d’affichage est réglé sur `Épisode spécifique`, mais aucun
épisode n’a pas été sélectionné. Sélectionnez un épisode ou revenez au mode `Dernier épisode`
.

**Question :** La page affiche le message « Le podcast ne comporte encore aucun épisode. »

Réponse : Le podcast existe, mais ne contient aucun épisode lisible. Vous devez d’abord
publier un épisode dans Staffbase.

**Question :** La page indique « Épisode introuvable. »

Réponse : L’épisode saisi n’existe pas (ou plus) dans ce podcast — par exemple
après une suppression ou si l’épisode et le podcast ne correspondent pas. Sélectionnez un nouvel épisode
ou passez en mode « Dernier épisode ».

**Question :** L’épisode affiché change tout seul.

Réponse : C’est exactement le comportement prévu en mode « Dernier épisode ». Si vous souhaitez que
le même épisode reste affiché en permanence, passez en mode « Épisode spécifique ».

**Question :** Pourquoi les options de vitesse et de
mise en sourdine sont-elles absentes du lecteur compact ?

Réponse : Le lecteur compact est volontairement réduit aux fonctions Lecture/Pause et progression
afin de s’adapter à des colonnes étroites. Si vous avez besoin de toutes les commandes,
sélectionnez la taille de lecteur « Grand ».

**Question :** Puis-je afficher plusieurs épisodes sous forme de liste ?

Réponse : Non, un widget ne lit qu’un seul épisode. Pour plusieurs épisodes,
placez plusieurs widgets.
