# FAQ

**Question :** Le widget affiche le message « Impossible de charger la liste des podcasts
» dans la boîte de dialogue de configuration — que faire ?

Réponse : Dans ce cas, vous pouvez saisir manuellement l'identifiant du podcast. La plupart du temps,
cela est dû à un dysfonctionnement temporaire de l'interface de podcast ; il suffit généralement
de rouvrir la boîte de dialogue pour résoudre le problème.

**Question :** Pourquoi l'épisode affiché change-t-il tout seul ?

Réponse : En mode d’affichage « Dernier épisode », c’est voulu — le widget affiche
toujours le dernier épisode du podcast sélectionné, sans aucune
intervention de votre part. Si vous souhaitez qu’un épisode spécifique s’affiche en permanence, passez en mode « Épisode spécifique »
et sélectionnez l’épisode souhaité.
