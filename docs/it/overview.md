# Visualizzazione podcast

La visualizzazione podcast incorpora un singolo lettore di podcast in una pagina.
Può mostrare sempre l’**episodio più recente** di un podcast — il
widget si aggiorna automaticamente non appena viene pubblicato un nuovo episodio —
oppure un **episodio specifico, selezionato in modo permanente**.

Il widget è adatto per le landing page dei podcast, le pagine dedicate al team o al canale, nonché
per singoli post che devono rimandare a un episodio specifico.
