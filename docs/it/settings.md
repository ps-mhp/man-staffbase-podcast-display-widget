# Impostazioni

| Impostazione | Descrizione |
| --- | --- |
| ID podcast | Il podcast da cui viene visualizzato un episodio. Campo obbligatorio. Di norma tramite l'elenco a tendina; in alternativa, inserire l'indirizzo completo del podcast. |
| Modalità di visualizzazione | `Episodio più recente` (impostazione predefinita) mostra sempre l'episodio più recente. `Episodio specifico` mostra in modo permanente l'episodio selezionato di seguito. |
| ID episodio | Attivo solo nella modalità `Episodio specifico`. L’episodio desiderato — tramite l’elenco a discesa oppure come ID o indirizzo completo del file audio. |
| Dimensione del lettore | `Grande` (impostazione predefinita): copertina, titolo, data, controlli completi inclusi velocità e silenziamento. `Compatto`: riquadro stretto con pulsante di riproduzione e indicatore di avanzamento. |

## Note

- Nella modalità `Episodio più recente`, un valore inserito in “ID episodio”
  viene semplicemente ignorato — non è necessario cancellarlo.
- L'elenco di selezione degli episodi si popola solo quando in alto è selezionato un podcast
  .
- La modifica delle dimensioni del lettore cambia solo la visualizzazione, non l'
  episodio in riproduzione.
