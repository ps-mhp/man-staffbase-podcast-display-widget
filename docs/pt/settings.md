# Definições

| Definição | Descrição |
| --- | --- |
| Podcast | O podcast do qual é apresentado um episódio. Campo obrigatório. |
| Modo de exibição | «Episódio mais recente» mostra sempre o episódio mais recente; «Episódio específico» mostra permanentemente o episódio selecionado abaixo. |
| Episódio | Visível apenas no modo de visualização «Episódio específico»: o episódio específico que deve ser apresentado. |
| Tamanho do leitor | «Grande» mostra a capa, o título e o controlo completo; «Pequeno» mostra uma linha compacta com Reproduzir/Pausa. |

O podcast e o episódio podem ser facilmente selecionados através do menu suspenso na
caixa de diálogo de configuração; caso, excecionalmente, não esteja disponível uma lista,
a respetiva ID também pode ser introduzida manualmente.
