# Definições

| Definição | Descrição |
| --- | --- |
| ID do podcast | O podcast do qual é apresentado um episódio. Campo obrigatório. Normalmente selecionado através da lista de opções; em alternativa, introduza o endereço completo do podcast. |
| Modo de exibição | `Episódio mais recente` (predefinição) mostra sempre o episódio mais recente. `Episódio específico` mostra permanentemente o episódio selecionado abaixo. |
| ID do episódio | Apenas válido no modo `Episódio específico`. O episódio pretendido — através da lista de seleção ou como identificador ou endereço completo do ficheiro de áudio. |
| Tamanho do leitor | `Grande` (predefinição): capa, título, data, controlo total, incluindo velocidade e silenciamento. `Compacto`: mosaico estreito com botão de reprodução e barra de progresso. |

## Notas

- No modo `Episódio mais recente`, qualquer valor introduzido em «ID do episódio»
  é simplesmente ignorado — não é necessário apagá-lo.
- A lista de seleção de episódios só se preenche quando um podcast
  é selecionado na parte superior.
- A alteração do tamanho do leitor altera apenas a apresentação, não o
  episódio que está a ser reproduzido.
