# Passo a passo

## Mostrar sempre o episódio mais recente

1. Abra a página de destino para edição e arraste o widget **Exibição de podcast** para o
   local pretendido.
2. Em **ID do podcast**, selecione o podcast a partir da lista de opções.
3. Deixe o **Modo de exibição** definido como `Episódio mais recente` (predefinição).
4. Selecione o **Tamanho do leitor**: `Grande` para áreas largas, `Compacto` para
   colunas estreitas.
5. Guarde e verifique na pré-visualização.

A partir de agora, o visor atualiza-se automaticamente sempre que for lançado um novo episódio.

## Mostrar um episódio específico

1. Abra a página de destino para edição e arraste o widget **Exibição de podcast** para o
   local pretendido.
2. Em **ID do podcast**, selecione o podcast da lista de opções.
3. Alterar o **Modo de exibição** para `Episódio específico`. Só assim é que o
   campo **ID do episódio** é utilizado.
4. Em **ID do episódio**, selecione o episódio pretendido da lista de seleção.
5. Selecione o **Tamanho do leitor**.
6. Guarde e verifique na pré-visualização.

## Se não aparecer nenhuma lista de seleção

Em vez da lista, aparecerá uma mensagem a indicar que os podcasts ou episódios não
puderam ser carregados. Nesse caso, introduza manualmente:

1. Para o **ID do podcast**: abra o podcast no Staffbase e cole o
   endereço completo da barra de endereços no campo.
2. Para o **ID do episódio**: cole o identificador do episódio ou o endereço completo
   do ficheiro de áudio no campo.
3. Guarde. Em ambos os casos, o widget obtém automaticamente o ID
   correto.

## Se faltar um podcast na lista

1. Clique na ligação **«Não consegue encontrar o podcast?»** abaixo da seleção — aí
   encontram-se as causas mais comuns.
2. Verifique se o espaço do podcast está acessível a partir desta página;
   apenas são listados os podcasts acessíveis.
3. Se necessário, introduza manualmente o ID do podcast — mas verifique se o
   público-alvo da página tem, de facto, permissão para ouvir o episódio.
