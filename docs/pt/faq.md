# Perguntas frequentes

**Pergunta:** O widget apresenta a mensagem «Não foi possível carregar a lista de podcasts»
na caixa de diálogo de configuração — o que fazer?

Resposta: Neste caso, o ID do podcast pode ser introduzido manualmente. Na maioria das vezes,
deve-se a uma falha temporária na interface do podcast;
normalmente, basta voltar a abrir a caixa de diálogo para resolver o problema.

**Pergunta:** Por que é que o episódio apresentado muda por si só?

Resposta: No modo de visualização «Episódio mais recente», isso é intencional — o widget mostra
sempre o episódio mais recente do podcast selecionado, sem que seja necessária qualquer
intervenção adicional. Se pretender que um determinado episódio seja exibido permanentemente, mude para «Episódio
específico» e selecione o episódio pretendido.
