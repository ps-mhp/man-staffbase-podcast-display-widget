# Einstellungen

| Einstellung | Beschreibung |
| --- | --- |
| Podcast | Der Podcast, aus dem eine Episode gezeigt wird. Pflichtfeld. |
| Anzeigemodus | „Neueste Episode“ zeigt immer die aktuellste Folge; „Bestimmte Episode“ zeigt dauerhaft die unten ausgewählte Folge. |
| Episode | Nur bei Anzeigemodus „Bestimmte Episode“ sichtbar: die konkrete Folge, die gezeigt werden soll. |
| Player-Größe | „Groß“ zeigt Cover, Titel und volle Steuerung; „Klein“ zeigt eine kompakte Zeile mit Play/Pause. |

Podcast und Episode lassen sich bequem über die Dropdown-Auswahl im
Konfigurationsdialog wählen; steht eine Liste ausnahmsweise nicht zur
Verfügung, kann die jeweilige ID auch manuell eingetragen werden.
