# Einstellungen

| Einstellung | Beschreibung |
| --- | --- |
| Podcast-ID | Der Podcast, aus dem eine Folge gezeigt wird. Pflichtfeld. Normalerweise über die Auswahlliste; ersatzweise die vollständige Podcast-Adresse einfügen. |
| Anzeigemodus | `Neueste Episode` (Voreinstellung) zeigt immer die aktuellste Folge. `Bestimmte Episode` zeigt dauerhaft die unten ausgewählte Folge. |
| Episode-ID | Nur im Modus `Bestimmte Episode` wirksam. Die gewünschte Folge — über die Auswahlliste oder als Kennung bzw. vollständige Adresse der Audiodatei. |
| Player-Größe | `Groß` (Voreinstellung): Cover, Titel, Datum, volle Steuerung inklusive Geschwindigkeit und Stummschaltung. `Kompakt`: schmale Kachel mit Play und Fortschritt. |

## Hinweise

- Im Modus `Neueste Episode` wird ein eingetragener Wert unter „Episode-ID“
  schlicht ignoriert — er muss nicht gelöscht werden.
- Die Auswahlliste der Episoden füllt sich erst, wenn oben ein Podcast
  ausgewählt ist.
- Ein Wechsel der Player-Größe ändert nur die Darstellung, nicht die
  abgespielte Folge.
